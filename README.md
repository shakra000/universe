# 🌌 Cosmic Explorer: Interactive Universe & Astronomy Suite

An immersive, educational web application designed to take users on an interactive journey through the cosmos. Built with a modern **Dark Cosmic UI**, it combines astronomical data, real-time interactive calculators, and space exploration features.

[![Live Demo](https://img.shields.io/badge/Live-Demo-00ff88?style=for-the-badge&logo=rocket)](https://shakra000.github.io/universe/)
[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg?style=for-the-badge)](LICENSE)

---

## ✨ Key Features & Interactive Tools

* **Planetary Stats Calculator:** Instantly calculate how much you would weigh and your relative age on Mars and Jupiter based on orbital periods and gravitational pull.
* **Solar System Explorer:** Detailed visual and statistical data for planets, cosmic numbers, and spatial metrics.
* **Cosmic Calculations & Stats:** Interactive counters for universe age (13.8B years), estimated galaxies (2 Trillion), and observable bounds (93B light-years).
